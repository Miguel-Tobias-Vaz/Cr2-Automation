# Mapa do site (WordPress)

Cria/atualiza páginas no WordPress e monta o **mapa do site** com links para o portal CR2.

## Executar

```powershell
cd automacoes
.\venv\Scripts\python.exe mapa-site\script.py
```

Edite `WP_URL`, `USER`, `APP_PASSWORD` e o dicionário `PAGINAS` no início de `script.py`.
