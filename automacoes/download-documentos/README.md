# Download de documentos

Baixa PDFs (e outros arquivos) a partir de **páginas** do site da entidade (folha de pagamento, RGF, balancete, etc.).

## Executar

```powershell
cd automacoes
.\venv\Scripts\python.exe download-documentos\script.py
```

Edite `PASTA_BASE`, `TIPO_DOCUMENTO` e `URLS_PAGINAS` no início de `script.py`.
